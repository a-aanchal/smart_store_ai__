# Screenshots and Demo Images

Place screenshots and images for the project in this folder.

Recommended filenames:
- `splash.png` — app landing / dashboard screenshot
- `products.png` — product listing view
- `product_form.png` — add/edit product form
- `analytics.png` — analytics/dashboard charts

When adding images, reference them in the root README.md under the Screenshots section. Example markdown:

![Dashboard](docs/screenshots/dashboard.png)
